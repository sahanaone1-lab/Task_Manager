# Task Manager System

A web-based Task Manager System developed during my internship.

## Features
- User Authentication
- Dashboard
- Task Management
- Calendar
- Habit Tracker
- Reports
- Responsive UI

## Technologies
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation
1. Clone the repository.
2. Import the MySQL database.
3. Place the project inside the `htdocs` folder of XAMPP.
4. Start Apache and MySQL.
5. Open `http://localhost/TaskManager`.
